# Community Audience Demo

An external-author demonstration repository for the Pupu Danmu declarative plugin catalog. It contains one generic audience persona and topic tags as data only. There is no prompt, executable code, user data, or fabricated claim.

## Release

The source and manifest live under `plugin/`. The tagged GitHub Actions workflow builds the ZIP and SHA-256 file and uploads them to the GitHub Release; generated ZIP files are not committed to this repository. The community Registry entry is reviewed in a separate pull request.
